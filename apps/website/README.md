# TaskFlow Website

Website-ul de prezentare este construit cu React și Vite. Include pagina principală și paginile de ajutor, documentație, articole și informații legale.

## Dezvoltare

```sh
npm ci
npm run dev
```

`npm run build` creează build-ul de producție în `dist/`; `npm run preview` îl servește local. Pentru deploy pe Vercel, folosește acest director ca **Root Directory**.
