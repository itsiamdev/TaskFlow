# TaskFlow Roadmap

Acest roadmap descrie pașii planificați pentru transformarea prototipului într-un produs complet. Ordinea poate fi ajustată pe măsură ce evoluează proiectul.

## Fundație

- [x] Organizează website-ul și aplicația mobilă într-un monorepo.
- [x] Configurează verificări automate pentru build, analiză și teste.
- [ ] Definește design system-ul și componentele partajate ale aplicației.

## Sarcini și planificare

- [ ] Creează, editează, șterge și organizează sarcini.
- [ ] Adaugă termene, priorități, categorii și filtre.
- [ ] Construiește calendarul și vizualizările de planificare.
- [ ] Sincronizează datele între dispozitive.

## Obiceiuri și progres

- [ ] Permite definirea și urmărirea obiceiurilor recurente.
- [ ] Adaugă statistici pentru sarcini finalizate și consecvență.
- [ ] Oferă notificări configurabile și preferințe personale.

## Lansare

- [ ] Adaugă autentificare și backup securizat.
- [ ] Testează accesibilitatea și performanța pe Android și iOS.
- [ ] Pregătește publicarea aplicațiilor în magazinele mobile.
